# Space Traders

A 2D sci-fi trading simulation game built with Flutter.

Play at: https://josealansys.github.io/space-traders/

## Features
- 9 planets with unique identities
- 9 commodities with dynamic prices
- Per-planet banks with credit system
- AI warehouse crews
- Encounters (pirates, police, traders)
- Fleet management with mix-and-match ships
- Smart mission filtering
- Insurance system
